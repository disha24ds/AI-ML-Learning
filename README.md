# 🤖 Task 1 – Understanding AI & Machine Learning

This task helped me understand the basic concepts of Artificial Intelligence and Machine Learning.

## 📚 Topics Covered

* **Artificial Intelligence (AI)** – Understanding how machines perform tasks that normally require human intelligence.
* **Machine Learning (ML)** – Understanding how computers learn patterns from data.
* **Deep Learning** – Understanding neural networks and how they are used for complex tasks.
* **Supervised Learning** – Learning from labeled data.
* **Unsupervised Learning** – Finding patterns and groups in unlabeled data.
* **Reinforcement Learning** – Learning through rewards and penalties.

## 🎯 Objective

To build a basic understanding of Artificial Intelligence and Machine Learning and learn how these technologies are used in real-life applications.
